Privacy Policy

LC Codex is a reference app. It shows public game information and does not ask you to create an account or provide any personal information.

🚫

We collect zero personal data

LC Codex does not collect, store, or transmit any personal data. There is no account, no login, and no user profile of any kind.

📚

What the app does

LC Codex reads champion, item, rune, and mastery reference data from our database and displays it in the app. This data is public game information — it is not tied to you, your device, or any identifier.

🌐

Network usage

LC Codex needs an internet connection to load reference data and images each time you use it. These requests only fetch content — they do not send any personal or device information beyond what's technically required for a network request to complete (e.g. standard connection info handled at the infrastructure level, not by us).

🚷

What we never do

  • No account or login required
  • No analytics or tracking
  • No advertising, ever
  • No data sold or shared with third parties
  • No access to contacts, location, camera, or microphone
🔄

Changes to this policy

If LC Codex ever adds a feature that changes how data is handled (for example, an optional account or stats lookup), this page will be updated first and the update will be reflected in the app.
